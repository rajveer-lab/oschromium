Phone handoff (YouTube)

On Android, with the free MacroDroid app: add a macro with the trigger Application Launched → YouTube and the action HTTP Request (method GET, URL: the link above), then save it. Turn off battery optimisation for MacroDroid so it can run in the background.
On iPhone, with the built-in Shortcuts app: open the Automation tab, tap + → App → choose YouTube with Is Opened ticked → Run Immediately → Next → New Blank Automation, then add the action Get Contents of URL with the link above as the URL, and tap Done.
Anyone with the link can pause YouTube here, so keep it to yourself; New link replaces it.
